# Hunting Hills Family Dentistry

Modern, responsive web application for **Hunting Hills Family Dentistry** — Roanoke, Virginia's premier cosmetic, implant, and family dental practice.

## Features

- 🌟 **Modern Design & Animations**: Clean, accessible UI with smooth micro-interactions.
- 🦷 **Comprehensive Services Showcase**: Detailed information on TeethXpress®, Dental Implants, Cosmetic Dentistry, Invisalign®, and Preventive Care.
- 👨‍⚕️ **Doctor Profiles**: Highlights of Dr. Richard D. Smith II, Dr. Karen L. Hutchison, and the clinical team.
- 🏆 **Roanoke Awards & Accreditations**: Showcase of Roanoker Magazine awards and clinical certifications.
- 📅 **Interactive Appointment & Contact Forms**: Seamless patient inquiries and consultation booking.
- 📍 **Interactive Office Info & Hours**: Live clinic open/closed indicator based on US Eastern Time and map directions.
- 📱 **Fully Responsive**: Optimized for mobile, tablet, and desktop viewing.

## Tech Stack

- **React 19**
- **Vite 6**
- **Lucide Icons**
- **Vanilla CSS Design System**

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/uiuxbyahsan/hunting-hills-family-dentistry.git

# Navigate to project directory
cd hunting-hills-family-dentistry

# Install dependencies
npm install
```

### Development

To start the local development server:

```bash
npm run dev
```

### Production Build

To build for production:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
